Installation Guide

The Blue Banana Security MCP is a tool that helps AI assistants analyze code for security issues. Follow these simple steps to connect it to your favorite AI platform.

What is an MCP?

An MCP (Model Context Protocol) is like a plugin for AI assistants. It gives them special abilities - in this case, the ability to analyze code for security problems.

Installing on Cursor

1

Open Cursor Settings

Open Cursor and click on the settings icon (⚙️) in the bottom left corner.

2

Find MCP Configuration

Look for "MCP" or "Model Context Protocol" in the settings menu.

3

Add This Configuration

{
  "bluebanana": {
    "serverUrl": "https://mcp-bluebanana.onrender.com"
  }
}
4

Save and Restart

Save your settings and restart Cursor if needed.

Installing on Windsurf

1

Find Your .windsurf File

Open your project folder and look for the .windsurf file. If it doesn't exist, create one.

2

Add This Configuration

{
  "bluebanana": {
    "serverUrl": "https://mcp-bluebanana.onrender.com"
  }
}
3

Save and Restart

Save the file and restart Windsurf if it's already running.

How to Use the Security MCP

1

Ask for a Security Analysis

After installation, simply ask your AI assistant to analyze your code for security issues.

Example: "Please analyze this code for security vulnerabilities using the Blue Banana Security MCP."

2

Review the Analysis

The AI will use the MCP to provide a detailed security analysis with:

  • Identified vulnerabilities
  • Severity ratings
  • Suggested fixes
3

Troubleshooting

If the MCP isn't working:

  • Check that you've added the configuration correctly
  • Make sure your AI platform supports MCPs
  • Try restarting your AI application
  • Verify your internet connection
